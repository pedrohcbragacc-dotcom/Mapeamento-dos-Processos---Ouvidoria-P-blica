# Mapeamento de Processos de Negócio para a Governança de Dados

Este repositório disponibiliza as imagens dos modelos de processos de negócio (BPMN) desenvolvidos no âmbito da pesquisa:

> **Modelagem de Processos de Negócio para a Governança de Dados: uma Abordagem Design Science Research para o Fortalecimento da Transparência nas Ouvidorias Públicas**

**Autores:** Sandro Luis Freire, Maria Cristina Drumond e Castro, Cristiane Paim Marques, Marcelo Fornazin, Rafael Moraes da Silva e Pedro Henrique da Costa Braga.

---

## Sobre as Imagens

As imagens disponibilizadas neste repositório representam o produto tecnológico da pesquisa (artefato). Os diagramas foram construídos utilizando a notação **BPMN (Business Process Model and Notation)**.

[Link para download](https://github.com/pedrohcbragacc-dotcom/Mapeamento-dos-Processos---Ouvidoria-P-blica/tree/main/Mapeamento%20dos%20processos)
